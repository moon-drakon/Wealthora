# Wealthora final academic materials

This directory contains supporting academic materials for the CSE 215 Section 11 project.

## Included materials

- `Wealthora_Final_Academic_Report.docx` — editable final report
- `Wealthora_Final_Academic_Report.pdf` — matching PDF report
- `Wealthora_OOP_Requirement_Traceability.md` — OOP/Swing code-to-requirement map
- `evidence/` — sanitized build, verification, traceability, and review records

Presentation-day logistics, dated rehearsal notes, and outdated presentation copies are intentionally not kept here. The current source code on the repository `main` branch remains the primary reference for code review.

No Gmail address, App Password, OTP, recovery answer, signing secret, encrypted local configuration, authentication record, private workspace, or finance data belongs in this directory or in a submission archive.
